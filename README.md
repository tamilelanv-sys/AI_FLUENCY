# Agentic AI: Foundations and Open-Source Practice

This project demonstrates three approaches to solving a private-data college fee scenario:

1. Plain Chatbot
2. Rule-Based Workflow
3. AI Agent

## Technologies

- Python
- OpenAI-compatible API
- Groq
- GPT-OSS-20B
- Function/Tool Calling
- Python-dotenv
